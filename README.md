🐍 Python - Simple Terminal Chat

This project is my first hands-on Python script, it simulates a simple terminal-based chat, where the user types their name and sends messages, which are stored and displayed in the terminal.
📋 What does the program do?

    Asks the user for their name.

    Allows the user to type multiple messages in a while loop.

    Stores each message in a list with the user's name.

    Displays all previous messages on the screen.

    Clears the terminal after each input to keep it clean.

    Ends the chat when the user types end.

🧠 Concepts applied

    Input and output with input() and print()

    Working with lists and dictionaries

    while loop for repeated interaction

    os.system('cls') to clear the terminal (Windows)

🧪 Example usage

Name: Karine
message: Hello!
message: How are you?
message: end

Output in the terminal:

Karine - Hello!
Karine - How are you?
